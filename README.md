# SEO Agent

Rank a business on Google with Claude Code. Seven commands, one repo, free.

```
git clone https://github.com/youtube-jono/seo-agent.git
cd seo-agent
claude
/keyword-research
```

## The path (run them in this order)

1. `/keyword-research` - keywords, filtered four ways (volume, difficulty, intent, cost per click), clustered into your build map
2. `/build-website` - the pre-built site in `website/` wearing your name: pick a style, real words, photos, one colour
3. `/blog-post` - one publish-ready blog post from the next keyword in the map, 30+ sources, top-3 results scanned, written with humour
4. `/service-page` - one money page from the next service keyword, written to convert, lead form wired
5. `/seo-optimization` - fix one page to 100: on-page, technical, images, speed, AI overviews, LLM discovery
6. `/publish` - ship it: GitHub + Vercel (or WordPress via Novamira), robots, sitemap, Search Console
7. `/audit` - already have a site? Start here. The whole-site audit: Semrush, on-page, technical, AI overviews, doorway pages, local - then fixed on a loop

Most commands don't get to 100 on the first run. Run them again - every pass improves the score.

## Requirements

- [Claude Code](https://claude.com/claude-code) installed (the VS Code extension is the easiest way in)
- Semrush - powers the keyword data and the audit crawl. [Start with the 14-day free trial](https://semrush.sjv.io/c/7401436/3945708/13053), then connect it in Claude Code: Settings → Connectors → search Semrush
- A GitHub account and a Vercel account for `/publish` (both free - the command walks you through creating them)
- WordPress users: the Novamira plugin + connection (lets Claude edit your site directly) - the first WordPress command you run walks you through it

There is no setup step. Each command asks for exactly what it needs, the first time you run it.
