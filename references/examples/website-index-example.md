## How to use this

1. Every page a command writes gets added here automatically. There are no pages that aren't on this list.
2. Read the ones under "needs your review" and say which are good to go.
3. Approved pages get a publish date, not an instant deploy - blogs go out 2 to 3 a week so the site grows naturally.
4. `/publish` moves anything whose date has arrived into "Live".
5. Never edit a page's section by hand - the commands move them as work gets done.
